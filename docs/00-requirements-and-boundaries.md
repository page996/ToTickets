# 需求与边界

## 1. 文档状态

- 版本：0.1.0
- 日期：2026-08-25
- 状态：首阶段基线，待用户审核
- 适用范围：个人本地部署的人工购票辅助控制台

## 2. 背景与问题

用户需要在演出开售前准备多个自有 Android 设备或模拟器，并在开售期间快速确认页面状态。当前设想包含账号分组、设备多开、统一计时、画面监控和人工付款交接。真正困难不只是界面点击，而是：平台验证具有随机性；不同票种和渠道限制不同；登录和实名信息属于高敏感数据；连续自动输入可能触发平台的安全策略；模拟器供应商的多开能力和许可也不一致。

因此，本项目把“控制台能否安全地让人完成工作”作为成功标准，而不是把订单成功率或自动化速度作为指标。

## 3. 目标

### 3.1 首阶段目标

1. 管理用户自有设备/模拟器的注册、分组、启动、停止、健康状态和连接错误。
2. 显示设备画面或由设备适配器提供的只读预览，支持人工切换焦点设备。
3. 管理演出任务、开售时间、时区和提醒策略；提供倒计时、声音/桌面提醒和确认记录。
4. 提供人工状态标记，例如“待登录”“等待人工验证”“已进入人工处理”“需要付款”“完成/失败”。
5. 以脱敏审计日志记录谁在何时启动了何设备、确认了何提醒和改变了何状态。
6. 用本地 mock App 验证状态机、批量管理界面、事件总线和设备适配器契约。

### 3.2 后续可评估目标

- 只读的可用性统计、连接质量和画面帧率。
- 单设备人工 UI 透传（必须显式开启、可见、不可录制/重放/广播）。
- 对公开、稳定、获授权的合作方接口进行只读信息同步。

## 4. 明确非目标

以下内容不属于本项目，并且应由代码审查和测试持续阻断：

- 自动登录、短信验证码读取或提交、验证码识别/代答。
- 识别按钮、票档或页面状态后自动点击、坐标宏、循环重试和高频输入。
- 多账号/多设备同步输入、广播输入、抢票号池编排或概率优化。
- 调用大麦未公开接口、逆向协议、抓取令牌、伪造设备信息或规避风控。
- 自动填写实名观演人、提交订单、锁票、选择支付方式、输入支付密码或确认支付。
- 保存账号密码、验证码、身份证号码、支付凭据、Cookie、Token 或完整录屏。
- 对真实订单做自动化回归、压测或“成功率”实验。

## 5. 角色与权限

| 角色 | 允许 | 禁止 |
| --- | --- | --- |
| 操作者 | 查看设备、启动/停止、设置提醒、人工操作焦点设备、标记状态 | 让系统代替其完成购买或支付 |
| 审计查看者 | 查看脱敏事件和健康指标 | 查看秘密、实名字段或控制设备 |
| 管理员 | 注册/分组设备、配置保留策略、轮换本地密钥 | 绕过人工确认或解锁禁用输入能力 |
| 开发/测试 | 使用 mock App、合成数据和沙盒设备 | 使用真实账号、真实订单或真实支付 |

## 6. 关键用户流程

### 6.1 准备阶段

操作者登记设备别名和连接方式，验证设备归属，创建演出任务并设置时区。系统仅保存平台名称、公开演出链接（如用户自行提供）、提醒时间和设备分组；登录在大麦 App 内由人完成。

### 6.2 验证与等待阶段

操作者打开大麦 App，遇到登录或验证时自行处理。控制台显示“等待人工验证”状态，不读取页面内容、不判断验证结果、不发送输入。操作者确认已准备好后，系统开始倒计时和健康监控。

### 6.3 开售阶段

系统到达提醒时间时发出本地通知，并展示各设备的连接、画面更新时间和人工状态。操作者自行在焦点设备上点击、选择、填写和付款。控制台只记录操作者的显式状态标记和提醒确认，不记录敏感页面内容。

### 6.4 收尾阶段

操作者将每台设备标为完成、失败、需要人工复核或取消。系统保存最小化审计事件，按保留策略清理临时帧和错误诊断。

## 7. 成功指标与红线

成功指标：设备连接成功率、预览新鲜度、提醒准时性、状态记录完整性、恢复时间和敏感数据零落盘。

红线指标：任何真实平台自动输入调用、任何秘密进入日志、任何未授权设备控制、任何不可解释的批量动作。红线触发时适配器必须拒绝请求并生成审计事件。

## 8. 待确认事项

- 已冻结运行时：NestJS/TypeScript 后端，Tauri + React/TypeScript 控制台；Rust 仅作为 Tauri 构建工具链，不承担业务服务端职责。
- 项目本地 Node/pnpm/Rust 工具链版本和隔离方式（见依赖与可复现构建文档）。
- 目标操作系统、设备数量上限、是否接受 Android Studio Emulator 或仅接受实体设备。
- 是否需要单机局域网访问，及管理员认证方式。
- 是否需要录制 mock App 的非敏感测试视频；默认不保留。
- 项目许可证和发布方式。
