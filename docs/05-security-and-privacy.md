# 安全、隐私与合规

## 1. 威胁模型

### 资产

- 本地设备连接授权、ADB keys 和模拟器快照
- 设备画面（可能短暂包含姓名、二维码、订单或支付信息）
- 操作者身份、任务时间和审计记录
- 控制台本地配置、进程句柄和端口

### 对手与事故

1. 同机其他用户读取本地数据库或临时帧。
2. 恶意网页通过浏览器或桌面壳 IPC 请求任意设备命令。
3. 错误配置把服务暴露到局域网/公网。
4. 供应商适配器参数注入或启动了非预期可执行文件。
5. 日志、崩溃转储、录屏或备份泄露秘密。
6. 操作者误把批量管理误认为批量输入，造成跨设备误操作。
7. 平台页面或模拟器更新改变行为，导致状态判断错误。

## 2. 安全目标

- 默认拒绝未知能力和未知命令。
- 真实平台没有自动化购买路径，即使 UI、API 或数据库被部分攻破也不能生成购买/支付动作。
- 敏感数据不收集、不落盘、不进入日志；画面只短时传输到本机焦点窗口。
- 每次操作可追溯到操作者、设备、意图、策略版本和结果。
- 设备断开、时钟不可信、策略加载失败时 fail closed。

## 3. 数据分类与处理

| 类别 | 示例 | 处理策略 | 保留 |
| --- | --- | --- | --- |
| L0 公开 | 演出名称、用户提供的公开链接 | 可存储，校验协议和长度 | 直到用户删除 |
| L1 运行元数据 | 设备别名、状态、帧时间戳、错误码 | 脱敏结构化存储 | 7-30 天可配置 |
| L2 个人信息 | 用户自定义备注、操作者标识 | 最小化、可删除、访问审计 | 7 天默认 |
| L3 高敏感 | 手机号、姓名、身份证、OTP、密码、Token、支付信息、二维码内容 | 系统不得接收或存储；若出现在画面只做内存转发 | 不保留 |

控制台数据库 schema 不得出现 L3 字段名。代码扫描应对 `password`, `otp`, `sms`, `id_card`, `payment`, `cookie`, `token`, `captcha` 等关键字做 denylist 审查，并允许文档中的禁止清单通过显式注释排除误报。

## 4. 身份与授权

- 已实现的启动门禁要求 `runtime-config.v3` 的 `bind_host` 是字面量 IPv4 `127.0.0.0/8` 地址或精确的 `::1`；`0.0.0.0`、主机名（包括 `localhost`）和其他 IP 均 fail closed。源码仍不提供编译期绑定地址默认值，部署者必须显式选择 loopback 地址。
- 当前版本尚未实现 TLS、强认证、RBAC 和 CSRF 防护，因此配置层不能放宽为非 loopback。未来远程部署必须先版本化修改配置契约、实现上述控制并通过安全验收；仅配置 `allowed_origins` 不能替代这些控制。
- 待实现的本地会话必须使用随机、短期、不可预测的 token；不放入 URL、日志或长期浏览器存储。
- 待实现的 RBAC 至少包含 `operator`、`auditor`、`admin`；每个设备还要有显式绑定关系。
- 服务端根据能力策略重算权限；客户端提交的 `capabilities`、`role` 或 `confirmed` 字段不可信。
- 管理操作需二次确认；急停可以立即停止设备进程，但不可执行任何输入。

## 5. 命令安全

### 5.1 允许的命令

`discover`, `start`, `stop`, `reconnect`, `health`, `preview_start`, `preview_stop`, `focus_select`, `schedule_ack`。

### 5.2 永久拒绝的命令/模式

`click`, `tap`, `swipe`, `type`, `input_text`, `broadcast`, `loop`, `retry_until`, `captcha`, `login`, `purchase`, `order`, `reserve`, `lock`, `pay`, `payment`, `id_card`, `otp` 以及这些词的大小写/别名/编码变体。

拒绝不能只依赖字符串过滤；命令模型本身不定义这些字段，适配器端口也不暴露这些方法。策略测试要构造未知字段、批量目标、过期票据和重复请求，确认均被拒绝。

### 5.3 进程与 shell

- 使用 `CreateProcess`/`subprocess` 的参数数组，不拼接 shell 字符串。
- 可执行文件路径、工作目录、环境变量和参数均来自供应商注册表，不接受前端原样传入。
- 子进程使用低权限账户、资源上限和独立临时目录；继承环境变量前先清理秘密。
- 停止和超时要杀掉进程树，并在审计中记录退出码；不自动重放任何输入。

## 6. 画面与录制

- 预览只发送焦点设备，服务端内存缓冲有大小和时间上限。
- 默认禁用截图下载、录屏、OCR、图像索引和云端上传。
- 若为 mock 测试需要录制，必须使用合成画面、显式开关、加密文件、最短保留期和测试后自动删除。
- UI 在画面区域显示“可能包含敏感信息”的状态提示和一键停止流按钮。
- 错误报告只保存帧尺寸、延迟和哈希，不保存帧像素。

## 7. 审计与事件完整性

审计事件至少包含：事件 ID、时间、操作者、设备、动作类型、意图、策略版本、确认 ID、结果、错误码和 correlation ID。秘密载荷永远不进入事件。

首版可用 SQLite append-only 表；每行包含前一行摘要哈希，导出时验证链完整性。审计删除只能按保留策略由管理员执行，并生成不可删除的 `audit.retention.applied` 摘要。

## 8. 供应链与许可证

- 锁定依赖版本并生成 SBOM；每次升级重新审查许可证和维护状态。
- 默认采用 MIT/Apache-2.0 组件；Grafana AGPL、Waydroid GPL 和闭源模拟器必须单独记录法律意见。
- 下载 scrcpy、模拟器镜像和驱动只使用官方发布渠道；校验签名/哈希并记录来源。
- CI 禁止测试脚本导入真实平台包名或访问真实域名；网络测试默认 deny。

## 9. 事件响应

发现秘密落盘、未知设备输入、异常网络暴露或供应商进程越权时：

1. 触发 `safety.stop-all`，停止适配器和预览流。
2. 隔离日志/数据库副本，禁止继续覆盖证据。
3. 撤销本地会话和 ADB 授权，删除临时帧/凭据缓存。
4. 记录影响范围、时间、版本和修复措施，不记录秘密本身。
5. 修复后运行负向测试和人工批准，再恢复设备。

## 10. 合规假设

本系统不是大麦官方客户端或授权代理。用户必须自行遵守大麦、模拟器、Android SDK、网络运营商和当地法律/合同条款。项目文档不提供绕过平台安全措施的指南；遇到条款不确定时，停止集成并请求人工/法务确认。
